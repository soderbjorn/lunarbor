# Release checklist

- [ ] Bump `versionCode` (Android) and `CFBundleVersion` (iOS)
- [ ] Run the full test suite on both platforms
- [ ] Order a test pizza in production. Eat test pizza.
- [ ] Check that the "pineapple" filter still shows Hawaiian pizzas
- [ ] Write release notes that aren't just "bug fixes and improvements"
- [ ] Upload to Play Console and App Store Connect
- [ ] Wait for App Review. Contemplate the void.
- [ ] Celebrate with pizza
